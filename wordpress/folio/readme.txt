Search the web, Wikipedia, and Grokipedia from a WordPress theme.

== Installation ==
1. In WordPress, go to Appearance → Themes → Add New → Upload Theme.
2. Choose folio-wordpress.zip and click Install Now, then Activate.
3. Visit the site home. Folio replaces the front page.

WordPress.com keeps www addresses redirected to the bare domain. zip1.ai is the primary address.
